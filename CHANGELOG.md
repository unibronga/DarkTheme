# Change Log

All notable changes to the "Unibronga One Dark" theme are documented in this file.

## [1.0.3]

- More screenshots in the README: Vue, Python, CSS and SCSS.

## [1.0.2]

- New screenshot and updated recommended settings in the README.

## [1.0.1]

- Comments are a calm gray; JSDoc and Python docstrings are a lighter gray.
- Values (numbers, strings, `true`/`null`) share one cream color.
- `const` names are green; `import`/`export`/`from` are red; control keywords (`if`, `for`, `try`, `typeof`) are blue.
- Vue: highlighted directives, `:`/`@`/`#` shorthands, `{{ }}` interpolation; components stand apart from HTML tags.
- JSON: keys are colored by nesting depth.
- HTML: text content and attribute values no longer render plain white.
- Python and PHP: full palette for keywords, functions, classes, variables and `self`/`$this`, including Pylance semantic highlighting.
- Markdown: bold colored headings by level, styled emphasis, quotes, links, code and tables.
- CSS/SCSS: a dedicated palette for selectors, properties, values, units, variables and at-rules.
